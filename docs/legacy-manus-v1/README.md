# Legacy Manus V1 Documentation

Thư mục này dùng để lưu các tài liệu cũ được tạo ở giai đoạn đầu dự án.

Các file trong đây chỉ dùng để tham khảo bối cảnh, không phải nguồn sự thật mới nhất nếu khác:

- `PROJECT_SUMMARY.md`
- Code hiện tại
- Checklist/worklog mới nhất

Nhóm tài liệu này cần được viết lại sau theo Simple Mode, FinanceLite, DailyRoutine và Resident Portal hiện tại.
