# ResidenceCore - cPanel deployment

- Node.js version: 22.x
- Application mode: Production
- Application root: `apps/residence-management`
- Application URL: `vireon.vn/app-portal/residence-management`
- Startup file: `app_wrapper.cjs`

Upload and extract the packed archive into the application root, run NPM
Install from Node.js Selector, configure the variables in
`env.production.example`, then restart the application.
